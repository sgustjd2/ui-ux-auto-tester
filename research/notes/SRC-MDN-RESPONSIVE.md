## Scope and applicability

- MDN's guide to responsive web design: media queries, flexible grids (flexbox, CSS grid with fr units), responsive images and media (max-width 100 percent, picture/srcset), the viewport meta tag, responsive typography (viewport units, calc), and breakpoints, with a mobile-first approach.
- Jurisdiction: GLOBAL. Rule class BEST_PRACTICE. Platform web (and responsive behavior across form factors).

## Candidate rules

- BEST_PRACTICE rule families: set a correct viewport meta tag; use fluid layouts rather than fixed widths; make media responsive (max-width 100 percent, responsive images); choose content-driven breakpoints; adopt mobile-first CSS; keep line length and type readable across sizes. Rule class BEST_PRACTICE, platform web, jurisdiction GLOBAL.
- These crosswalk to WCAG 1.4.10 Reflow (SRC-W3C-WCAG22) for the accessibility obligation; the MDN rules are the practitioner best practices around it. Extraction deferred to Phase 2.
