## Scope and applicability

- Chosen over Hull (1932) because it tests the goal-gradient effect with people, including an online setting. The abstract reports that café reward-program members bought more often as they neared a free coffee; that web users rating songs for rewards visited more, rated more per visit, and persisted longer as they approached the reward; that an illusion of progress (a card with bonus stamps already filled) sped completion; and that stronger acceleration predicted retention. It models effort as a function of the proportion of the original distance remaining to the goal.
- Interface relevance (this project's application): visible progress toward a goal (steps, progress bars, completion states) sustains effort, and apparent progress changes behavior. The same finding marks a manipulation risk: artificial progress used to pressure users belongs with the deceptive-pattern sources (OTH-DARK-PATTERNS), not with this rule.
- Rule class HEURISTIC; never a compliance requirement.

## Candidate rules

- KIVETZ-progress-001: multi-step tasks show honest progress toward completion; HEURISTIC, SHOULD; testability visual FULL, manual FULL. UX_RISK when a long task gives no sense of progress; crosswalk `see_also` to deceptive-pattern rules when progress is fabricated.
