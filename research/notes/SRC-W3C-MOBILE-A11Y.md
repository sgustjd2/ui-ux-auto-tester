## Decision: REJECTED as a source (resolves GAP-024)

The document's own Status of This Document section makes it unusable as a research source:

- It is a First Public Working Draft from 26 February 2015, over a decade old.
- It states it "is intended to become a Working Group Note" and was never finished.
- It states "It is inappropriate to cite this document as other than work in progress".
- It states "The group does not expect this document to become a W3C Recommendation".
- It maps WCAG 2.0, not the current WCAG 2.2.

Per `docs/standards-research-plan.md` §5 (a source's status must be current and citable) this draft cannot ground rules. It is marked REJECTED in `research/sources.md`.

## Replacement for the A11Y-MOBILE-WCAG domain

Mobile application of WCAG is covered by:

- WCAG2ICT (SRC-W3C-WCAG2ICT), the current W3C guidance on applying WCAG 2.0/2.1/2.2 to non-web documents and software (including native mobile apps), VERIFIED 2026-09-02; and
- the platform accessibility sources Apple accessibility (SRC-APPLE-A11Y) and Android accessibility (SRC-GOOGLE-ANDROID-A11Y), still to be verified.

A11Y-MOBILE-WCAG is therefore re-pointed to those sources and set PARTIAL (WCAG2ICT verified; platform sources owed).
