## Scope and applicability

- Apple's accessibility design guidance. It frames an accessible interface as intuitive, perceivable, and adaptable, and covers vision, hearing, physical and motor, and cognitive considerations across Apple platforms.
- Jurisdiction: GLOBAL. Rule class PLATFORM. It is one of the platform sources that, with WCAG2ICT, covers mobile WCAG application (A11Y-MOBILE-WCAG).

## Structure and key content (read from the rendered page)

- Principles: Intuitive, Perceivable, Adaptable.
- Vision: support larger text sizes (enlarge text by at least 200 percent, 140 percent in watchOS); adopt Dynamic Type (the systemwide text-size setting); use recommended default and minimum type sizes per platform (for example iOS/iPadOS 17 pt default, 11 pt minimum; macOS 13/10 pt; tvOS 29/23 pt; visionOS 17/12 pt; watchOS 16/12 pt); meet color-contrast minimums, referencing WCAG Level AA and the APCA algorithm.
- Tools: Accessibility Inspector; Accessibility Nutrition Labels on the App Store.

## Candidate rules

- PLATFORM rule families: Dynamic Type support and text scaling; color contrast (deferring to WCAG AA); VoiceOver and assistive-technology support; reduce motion; sufficient touch targets. Rule class PLATFORM, platforms ios/ipados/macos, jurisdiction GLOBAL. The text-scaling and contrast rules crosswalk to WCAG (1.4.4, 1.4.3).
