# Source Registry

One row per source. This file holds facts about sources; progress lives in `research/ledger.md`, per-domain status in `docs/standards-coverage.md`, and unresolved questions in `research/gaps.md`. Protocol for adding or verifying a row: `docs/standards-research-plan.md` §4. Vocabularies: `docs/standards-research-plan.md` §6.

Rows were seeded in Phase 0 (2026-09-02) from general knowledge as a worklist and are verified one at a time in Phase 1. A row's URLs, versions, statuses, licenses, and "expected:" notes are unverified until `research_status` is VERIFIED with a `last_checked` date; do not cite a CANDIDATE row as a fact. Verification progressed through Phase 1 by source group; as of 2026-09-23 every group is verified except ISO 9241 (BLOCKED, paid, no access), and no CANDIDATE rows remain. Rows added during Phase 1: the Digital Inclusion Act (2026-09-02) and twelve rows from the September 2026 landscape update (2026-09-23: ARIA in HTML, Accname, ACT Rules Format and list, WCAG 3.0 watch-only, EN 301 549 V4.1.1, klreq, Toss tech blog, Apps in Toss, Android app quality, KRDS, NIKL public-language guide), and eight rows in session 10 (2026-09-23: seven interaction-law papers and Unicode UTS #35), so the seed count of 47 is now 68. Non-normative tools and industry precedents live in `research/landscape.md`, not here (ADR 0007). The current per-status counts live in `research/ledger.md` (the harness check keeps them and this file consistent); read each row's `research_status` for its own state.

Columns:

- `source_id`: `SRC-<AUTHORITY>-<SHORT>`, uppercase, hyphens.
- `tier`: T1–T4 per `docs/standards-research-plan.md` §3.
- `canonical_url`: the authority's own location for the current version.
- `version`: version or date string as published; `unverified` until checked.
- `source_status`: CURRENT, SUPERSEDED, DRAFT, DEPRECATED, WITHDRAWN, UNKNOWN. A SUPERSEDED row names the successor in `notes` as "superseded by SRC-...".
- `research_status`: CANDIDATE, IN_PROGRESS, VERIFIED, BLOCKED, REJECTED. A VERIFIED row needs `last_checked`, `version`, `license`, a non-UNKNOWN `source_status`, and a note file.
- `last_checked`: YYYY-MM-DD of the last verification at the canonical URL; `—` if never.
- `license`: license or access restriction as recorded during verification.
- `domains`: domain IDs from `docs/standards-coverage.md`; must mirror that file's `source_ids` (the harness check enforces both directions).
- Umbrella rows are placeholders only when one row stands in for several distinct documents that each need their own metadata (for example separate WCAG versions); split those into specific IDs and set the umbrella row to REJECTED with "split into SRC-...". A homogeneous living reference library under one authority (MDN, the NN/g article collection) is not a placeholder: it stays a single VERIFIED row, with individual pages cited per rule in Phase 2 (`docs/standards-research-plan.md` §4).
- Cells must not contain the `|` character; a wrong cell count fails the check.
